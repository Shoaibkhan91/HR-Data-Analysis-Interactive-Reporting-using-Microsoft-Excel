#  HR Data Analysis & Interactive Reporting using Microsoft Excel

##  Project Overview

This project focuses on analyzing Human Resource (HR) data using Microsoft Excel. It demonstrates an end-to-end HR analytics workflow, including data cleaning, transformation, KPI development, Pivot Table analysis, and business reporting to help organizations make data-driven workforce decisions.

The project uses Excel's advanced features to analyze employee information, attrition, salary distribution, hiring trends, and performance metrics.

---

##  Business Objective

The objective of this project is to analyze employee data and generate meaningful HR insights to support workforce planning, employee retention, and performance management.

The project answers business questions such as:

- How many employees have left the organization?
- What is the employee attrition rate?
- Which departments have the highest-performing employees?
- What is the average salary by department?
- Are male or female employees paid more on average?
- How has hiring changed over the years?
- Are there employees with high salaries but poor performance?
